# waterGLKN
This package contains functions that import database views from the Inland Lakes or Big Rivers data packages 
and provides functions to query, summarize, and visualize Great Lakes Network (GLKN) water quality and quantity data. 
The R package can be installed using `pak::pkg_install('doi-nps/waterGLKN')`. Previous archived versions of this 
R package can be found at <a href="www.github.com/katemmiller/waterGLKN"> www.github.com/katemmiller/waterGLKN</a>

This package includes the following functions: 
<ul>
<li>importData: Import views from data package as a zip file or folder containing csvs. Can import multiple 
data packages, but will drop any columns not in common between them.</li>           
<li>getLocations: queries location information common across inland lakes and big rivers.</li>
<li>getResults: queries GLKN water chemistry data that were measured in the lab.</li>
<li>plotLakeProfile: plots metrics collected in lake profiles.</li>     
<li>plotScatterPlot: plots a scatterplot of 2 water quality or quantity metrics.</li>    
<li>plotTrend: plots a water metric over time and includes option to add loess smoother.</li>           
<li>plotWaterBands: plots current year of water in comparison to the distribution of water data collected in specified previous years.</li>      
<li>sumEvents:  Summarize the number of samples collected at each site by year, month, and parameter.</li>
<li>theme_WQ: custom ggplot2 theme for plotting GLKN water data.</li>  
</ul>

The docs/ folder includes multiple files that are useful for automated reporting and the tutorial website: 
<ul>
<li>index.Rmd and its output index.html are the files that generate the <a href = "doi-nps.github.io/waterGLKN">
waterGLKN tutorial website</a>. </li> 
<li>header_manual.html generates th NPS banner for the tutorial website header.</li>
<li>www/ folder contains the css and images sourced in the RMDs.</li>
<li>data/ folder contains data frames that improve package function, including list of active sites (active_sites.rda),
and list of water quality metric abbreviations (GLKN_WQ_abbreviations.rda). These are both generated by scripts in the
scripts folder: </li>
  <ul>
  <li>scripts/active_sites.R: generates the list of active sites. If these have changed since the 2025 published data 
  packages, update the data packages in this script to update the active site list. </li>
  <li>scripts/parameter_abbreviations.R: if new parameters are collected, or abbreviations need to be updated, change here.</li>
  </ul>
</ul>
